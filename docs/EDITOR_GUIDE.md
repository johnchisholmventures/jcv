# How to add a resource (for John)

You no longer need to email anyone or use GitHub.

## 1. Open the editor

Go to: **https://YOUR-SITE.com/admin**

Sign in with the email you were invited with.

## 2. Create a new post

1. Click **Resources / Posts**
2. Click **Create new**
3. Fill in:

| Field | What to put |
|--------|-------------|
| **Title** | Full title of the talk, article, or interview |
| **Short summary** | 1–2 sentences for the homepage list |
| **Publish date** | When it was published or presented |
| **Content type** | See below |
| **Topics** | Check any that apply (Entrepreneurship, AI, etc.) |
| **Cover image** | Optional picture (use the upload button) |
| **Featured** | Turn on only if it should appear in the top carousel |
| **Body** | Full text, or a short note for videos |

### Content type

- **Article** — text lives on this website  
- **Video** — paste the **YouTube video ID** only  
  - From `youtube.com/watch?v=**ABC123**` use `ABC123`  
  - From `youtu.be/**ABC123**` use `ABC123`  
- **External link** — paste the full URL (Forbes, Amazon, podcast, etc.)

## 3. Save

Click **Save**.

Within a few minutes the live site updates automatically.

## Drafts

Turn on **Draft** to keep something hidden until you’re ready. Turn it off and save to publish.

## Need help?

If something looks wrong after saving, contact your site maintainer with a screenshot of the form (not the markdown file).
